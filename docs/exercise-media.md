## Runtime behavior

Tap an exercise heading on Today (including previews and active workouts), onboarding Weights, or onboarding Review. A scrollable React Native modal shows the guide with a persistent close button; Android Back and web Escape dismiss it. No dependency, account, storage migration or training-state write is added.

Text ships with the app and works offline. Only an open guide requests a YouTube thumbnail from `https://i.ytimg.com/vi/VIDEO_ID/hqdefault.jpg`; the existing native lift illustration remains underneath and is shown if loading fails. The thumbnail card opens the attributed video externally using React Native Linking, with an inline retry message if opening fails. Playback needs internet; there is no autoplay, iframe, downloaded video or heavy player dependency. External availability may change; URL tests check structure and documentation consistency offline, not ongoing playback.

All image fields are deliberately null until licensed local artwork exists. The typed nullable path reserves `assets/exercise-images/`; the paths above are future destinations, not broken runtime requests. A later artwork change must bundle assets with static React Native requires and wire them into rendering. No R5/R6 artwork or other feature is implemented here.
